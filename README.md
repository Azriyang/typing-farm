# 牧场打字物语 · Typing Farm

> 把《牧场物语》的日常劳作，全部交给指尖。
> 每一种农活都是一次打字 —— `hoe` 开垦、`water` 浇水、`chop` 砍树、`harvest` 收获。

一个跑在浏览器里的像素风农场经营游戏。纯本地运行，存档在 localStorage。

---

## 快速开始

```bash
pnpm install
pnpm dev            # 开发 → http://127.0.0.1:5180/

pnpm build          # 打包
node serve.mjs      # 运行打包版 → http://127.0.0.1:5181/
```

Windows 上更省事：**双击 `play.bat`**，自动起服务器并打开浏览器。

> 打包产物是普通静态文件，但用了 ES module，浏览器不允许 `file://` 直接打开，
> 所以需要一个本地服务器（`serve.mjs` 是零依赖的 20 行实现）。

## 核心系统

### 五把工具，五种打字节奏

工具不是数值乘数，每把都有自己的手感：

| 工具 | 目标 | 打字模式 | 体力 | 一句话 |
| --- | --- | --- | --- | --- |
| 🔨 锄头 | 未开垦的地 | 一个词 | 4 | `hoe` / `dig` / `plow` |
| 🚿 水壶 | 已播种的作物 | 一个词 | 2 | `water` / `soak` / `drench` |
| 🪓 斧头 | 树 | **同一词连打 3 遍** | 6 | 连砍三下，树就倒了 |
| ⛏️ 镐 | 岩石 | **长词重击**（时限 -20%） | 7 | 两下敲碎一块 |
| 🌾 镰刀 | 杂草 | **3 个短词快打**（每个 2.5 秒） | 2 | `cut` `mow` `trim` |
| 🎣 钓竿 | 池塘水面 | **等待 + 瞬间反应** | 5 | 抛竿打 `cast`，咬钩后 1.2 秒内按空格 |

拿错工具时，只要快捷栏里有对的那把，会**自动换上**并提示。

### 背包与快捷栏

- 背包初始 **16 格**，可扩容到 24 / 32（2000G / 5000G）
- 快捷栏 **8 格**，放工具和种子，`1~8` 直接选
- 作物按「种类 + 品质」分堆，5 星萝卜和 1 星萝卜不混
- 背包满了会**拒绝操作**并提示，绝不静默吞物品

### 材料与升级

砍树得木材、挖石得石材、割草得纤维。工具升级需要材料，于是**想去升级锄头，就得先拿起斧头和镐**：

| 升级 | 金币 | 材料 |
| --- | --- | --- |
| 银 | 600 | 木材 ×8（斧/镐要石材 ×10） |
| 金 | 1800 | 石材 ×20 |
| 秘银 | 4200 | 木材 ×30 + 石材 ×30 |

等级效果：银 = 容错 1 次；金 = 时限 +25%；秘银 = 容错 2 次 + 掉落翻倍 / 范围操作。

### 工具耐久

每把工具有耐久，**每干一次活就磨损**（徒手的播种、收获不算）。耐久见底就坏了，必须修好才能继续用。

| 等级 | 耐久上限 | 每次磨损 | 修满费用 |
| --- | --- | --- | --- |
| 铜 | 100 | 1 | 60G |
| 银 | 140 | 1 | 120G |
| 金 | 180 | 1 | 180G |
| 秘银 | 240 | 0.5 | 240G |

- 耐久低于 **20%** 会提示「快磨坏了」，坏了会提示「得修一修」
- 快捷栏每把工具下方有一条**耐久条**，绿→橙→红
- 订购箱「工具」区每行显示 `耐久 85/100`，有磨损时出现「修 60G」按钮
- **升级会顺带修满**——换了把新工具，耐久按新等级的上限重置
- **修理只收金币，不收材料**：否则「修工具要石材 → 石材要镐挖 → 镐也坏了」会死锁

按铜级算，100 耐久大约能干 3~4 天的活，撑一周就得修一次——修理变成了像浇水一样的例行小事，但不至于逼玩家天天跑。

### 资源节点

| 节点 | 数量 | 击打 | 产出 | 刷新 |
| --- | --- | --- | --- | --- |
| 树 | 12 棵 | 1 次（3 连砍） | 木材 2~4 | 3 天后从树桩长回 |
| 岩石 | 8 块 | 2 次 | 石材 2~3 | 5 天后恢复 |
| 杂草 | 每天 5~8 丛 | 1 次 | 纤维 1~2 | 每天重新长出（上限 20） |

### 钓鱼

池塘边面朝水面按空格，拿起钓竿。流程和农活完全不同：

```
打一个词抛竿  →  盯着浮标（等 0.9~3.6 秒）  →  咬钩！1.2 秒内按空格
              →  打一个词收线  →  上钩
```

- **反应越快星级越高**：窗口前 15% 内提竿是 5 星，越慢越低，最低 1 星
- 等太久会「鱼吐钩跑了」，抛竿太早只会提示「还早呢」
- 收线要打的词**跟着鱼的价值走**：30G 的鲤鱼只要打入门档短词，520G 的锦鲤要打高手档长词
- 钓竿等级提升咬钩窗口：铜 1.2s → 银 1.45s → 金 1.7s → 秘银 1.95s，秘银还会让稀有鱼更容易上钩

| 鱼 | 售价 | 收线难度档 | 稀有度 |
| --- | --- | --- | --- |
| 鲤鱼 | 30 | 入门 | 常见 |
| 鳊鱼 | 45 | 入门 | 常见 |
| 鳟鱼 | 70 | 轻松 | 普通 |
| 鲈鱼 | 95 | 轻松 | 普通 |
| 鲶鱼 | 130 | 中等 | 少见 |
| 鲑鱼 | 180 | 进阶 | 少见 |
| 鳗鱼 | 230 | 进阶 | 稀有 |
| 鲟鱼 | 330 | 困难 | 稀有 |
| 锦鲤 | 520 | 高手 | 传说 |

一条平均约 77G，是**可再生的现金流**——不像树和岩石有恢复周期，池塘随时能钓。

### 动物：每天必做的小事

动物补上一段固定照料循环，和钓鱼互补（钓鱼考反应、随时能做；动物考照料、每天必做）。

**鸡 🐔 / 牛 🐄 / 羊 🐑**：订购箱购买（鸡 600G / 牛 2200G / 羊 1200G），养在地图下方的鸡舍 / 牛棚围栏里（牛羊同住牛棚），每种最多 6 只。动物会在围栏里溜达。走到动物身边面朝它按空格，打开照料面板。

| 动作 | 节奏 | 体力 / 时间 | 效果 |
| --- | --- | --- | --- |
| 喂食 | 一个词 | 2 / 10min | 当天喂了，**明天才有**蛋 / 奶；心情 +8 |
| 捡蛋 / 挤奶 | 捡蛋一个词；**挤奶三连短词** | 2 / 5min · 4 / 15min | 收产物进背包 |
| 剪毛 | **三连短词** | 4 / 20min | 羊毛满 100% 才能剪，剪完归零 |
| 抚摸 | 一个词 | 1 / 5min | 心情 +6 |

**心情 → 品质**：心情 0~100 决定蛋 / 奶的基础星级（每 25 点一星），打得完美再 +1。喂食 + 抚摸涨心情，**饿着过夜掉 15**。于是「把动物照顾好」和「打字打得准」一样能变现。

**产物**：鸡蛋 70G / 牛奶 160G / 羊毛 280G（基准价，随品质最高 1.9×），和作物、鱼一样在出货箱卖。定位是**中期投资**——比种菜稳、比钓鱼省心，但要天天照料。

**羊的节奏不一样**：它不产「每日产物」，而是**攒羊毛**。每晚喂食 +34%，约 3 天攒满 100% 才能剪一次。剪一次 280G，比蛋奶值钱，但周期长——是「耐心换高单价」的选择。羊的毛长满时身体会明显变蓬松，一眼能看出该剪了。

**动物命名**：每只动物有默认名（鸡1、羊2…），面板里点「改名」可以起个自己的。

新买的动物带一份「见面礼」产物，让你立刻见到收获动作，随后学会「喂了明天才有」的节奏。

### 繁殖：让动物会「长大」

不只是「过夜随机多一只」，而是完整的成长链：

```
两只同类成年动物（心情 ≥70、当天都喂过）
   → 配种（打一个词）
   → 母方怀孕 2~3 天
   → 生下一只幼崽
   → 幼崽养 4 天长大
   → 成年后才开始产出
```

| 动物 | 怀孕天数 |
| --- | --- |
| 鸡 | 2 天 |
| 牛 / 羊 | 3 天 |

**几个刻意的设计**：

- **幼崽不产出**：`isProductReady` 直接返回 false，羊毛也不涨。养大前只有投入没有回报，成长才有分量
- **幼崽画小一号**（0.62 倍）并标「幼」，怀孕的标「♥」——围栏里一眼看出状态
- **配种消耗双方的当日喂食**：防止同一天反复配种刷数量
- **只让玩家点的那只怀孕**，配偶不怀孕，避免一次配种双倍产出
- **围栏上限 6 只**（含幼崽），满了就不生
- **幼崽长大后给一份产出**，让玩家立刻看到「养大了」的回报

**配种条件**：两只都成年、心情 ≥70、当天都喂过、都没怀孕。面板会直接告诉你缺什么。

### 四季：给经营加上时间维度

一年 32 天，每季 8 天：**春 🌸 → 夏 ☀️ → 秋 🍂 → 冬 ❄️**，循环。季节把「种什么只看利润」变成「什么季节种什么」的规划题。

**作物适季**：每种作物有适宜季节，**当季正常长，反季慢一倍**（用生长累积实现，跨夜保留进度，不浪费已浇的水）。

| 季节 | 当季作物 |
| --- | --- |
| 春 | 萝卜、土豆、草莓 |
| 夏 | 番茄、玉米 |
| 秋 | 卷心菜、南瓜 |
| 冬 | 菠菜（新增） |

**季节视觉**：地图随季节换色板——春嫩绿、夏深绿、秋橙黄、冬雪白，树冠同步变色。换季时重绘底图，冬天不开花。

**季节天气**：春雨多（35%）、夏晴（15% 降水）、秋爽（20%）、冬飘雪（40%）。**雨自动浇灌，雪不会**——冬天得手动浇水，多一件例行小事。

**提示**：HUD 显示「季节 · 第几天」；订购箱给每种种子标「当季 / 反季慢一倍」；换季那晚弹提示；反季播种会提醒。

### 节日：每季最后一天的期待

每季第 8 天（第 8 / 16 / 24 / 32 天）是节日，**只在当天有效**，给四季加上期待感。

| 季节 | 节日 | 效果 |
| --- | --- | --- |
| 春 | 🌱 播种祭 | 种子半价（商店显示划线原价） |
| 夏 | 🎆 夏日祭 | 体力消耗减半 |
| 秋 | 🌾 丰收祭 | 出货价格 +50% |
| 冬 | ✨ 星霜祭 | 所有产出品质 +1 星 |

四个节日对应四种资源**加速器**：更便宜地投入（种子）、更省力地干活（体力）、更高地变现（出货）、更好地提质（品质）—— 都是「今天该干什么」的节奏提示。

- **睡前预告**：第 7 天睡觉时会提示「明天是播种祭！」
- **HUD 徽章**：节日当天顶栏出现带呼吸动画的节日标签
- **出货提示**：丰收祭当天出货面板顶部标明「今天出货价格 +50%」

节日只影响当天，不做累计加成，避免鼓励「攒到节日再玩」的拖延策略。

### 小镇：补上社交维度

沿农场东边的路一直走就到小镇。地图向右扩建（农场在左、小镇在右），有 4 位村民在街上走动：**阿茂（老农）、小渔（渔夫）、掌柜（杂货店主）、阿晴（爱花的姑娘）**。

**对话 = 打字**：面朝村民按空格 → 聊天 → 打出他们说的英文短句（附中文）涨好感。这是社交轴的核心接法。

**好感**：用心形粗略表示（每 20 点一颗心，后台计算），每人每天限聊一次。掌柜好感够高时种子打折。

**送礼**：从背包选一件送给村民。**不显示数值增减、不预告喜恶**——送出去后村民会说一句话，玩家靠语气判断送得对不对：

> 送对了：“哎呀，这正是我需要的，多谢！”
> 送错了：“这个…店里可不收这种货啊。”

投其所好（农夫爱作物、渔夫爱鱼、掌柜爱蛋奶、阿晴爱草莓和纤维）涨得多，送错掉好感。喜好要靠自己摸索。

**小镇杂货店**：镇里的杂货店和农场订购箱相通，随时能买卖。

### 进屋：住宅 / 鸡舍 / 牛棚

走到门前按空格就能**真正走进室内**，不是弹窗。

| 建筑 | 室内 |
| --- | --- |
| 住宅 | 床（走到床边按空格睡觉）、书架（看图鉴）、桌子、地毯 |
| 鸡舍 | 鸡窝、饲料槽、干草堆；**能直接照料这里的鸡** |
| 牛棚 | 两排饲料槽、干草堆；照料牛和羊 |

- 室内是独立场景：木地板 / 石地板、暗色木墙、家具都有独立造型
- 屋里的门在下方，走到门口按空格出去
- **动物在室内也会显示**——按序号排在棚里，走过去就能喂食 / 捡蛋 / 挤奶 / 剪毛
- 睡觉必须在床边，不能站在屋外睡
- 存档会记录你所在的场景，读档回到当时那间屋

> 这是**场景系统**：地图尺寸不变，室内只用地图形状。以后加矿洞、酒馆、村民家都只是「多一个场景」，不用再改架构。

一开始只有 **24 块耕地**（6×4）。订购箱「其他」里有「🌾 开垦新耕地」，2500G 再开出 **12 块**（3×4），总数到 36 块。

- 未开垦的地在图上是普通草地，走过去按空格会提示「这块地还没开垦」
- 买地当场变成泥土、可以立刻开垦播种
- 这是纯产能投资：地的数量直接决定「一天能种多少」，配合四季和工具升级才是完整的经营循环

### 词库：打什么词，和做什么事是分开的

动作只声明「我需要一个多难的词」，词本身来自词库。**难度 = 价值**：值钱的东西要求更难的词。

难度不只看长度。每个词有一个**难度分**，以字母数为基础，再按真实手感修正：

- 连续重复字符（`zzzz`）→ 减分，按住一个键连打太容易
- 字符多样性低 → 减分
- 同手连击（左手或右手连续敲）→ 加分，比左右交替慢
- 罕见字母 q/z/x/j → 少量加分

所以 `zzzz` 和 `plow` 一样是 4 个字母，但难度分 1.15 vs 4.5，**时限也差 34%**。

价值映射到 7 个难度档：

| 价值 | 难度档 | 大致词长 |
| --- | --- | --- |
| < 50G | 入门 | 3~4 |
| 50~100G | 轻松 | 4 |
| 100~180G | 中等 | 4~5 |
| 180~300G | 进阶 | 5~6 |
| 300~450G | 困难 | 6~7 |
| 450~650G | 高手 | 7~8 |
| > 650G | 极限 | 9+ |

实测：草莓（640G）收获打 `harvest` `seedling`，萝卜（90G）打 `husk` `loam`。

内置六个分类：**耕作 / 砍树 / 挖矿 / 割草 / 钓鱼 / 照料**，共 201 个词，每档都有覆盖。

**取词用洗牌袋**：把该档的词洗牌后依次发完再重洗，保证一轮内不重复，再叠加「最近 8 词避让」，不会来回就那几个。

**自定义词库**（顶栏 📖 词库）：

- 粘贴一串单词（空格、逗号、换行都行），只保留英文字母，长度 2~14，按难度分自动归档
- 保存前有**难度分布预览**，输入时实时显示「识别 N 词 · 入门×2 中等×1 …」
- 界面有一张**档位覆盖表**：每类 × 每档的词数，空档标红并提示「会向邻近档借词」
- 可绑定到某个分类，或「全部动作」
- **一旦启用某分类的自定义词库，该分类就只用你的词**，内置词不再掺进来
- 支持启用/停用/编辑/删除，以及 JSON 或纯文本导入导出
- 存在 `localStorage` 的 `typing-farm-wordsets-v1`，与游戏存档独立

## 一天是怎么过的

```
06:00 起床
  ↓  走到目标旁 → 空格 → 打字 → 完成一次劳作（时间 +n 分钟，消耗体力）
  ↓  22:00 之后劳作，体力消耗翻倍
  ↓  凌晨 2:00 还没睡 → 直接累倒
回屋睡觉
  ↓  浇过水的作物生长一阶段，没浇水的原地不动
  ↓  树/岩石按天数恢复，杂草重新长出
  ↓  天气重掷（25% 下雨，雨天自动浇水）
次日 06:00，体力回满
```

体力耗尽会晕倒，扣 20% 金币当医药费。

## 设计思路

游戏乐趣来自三条互相牵制的轴：

| 轴 | 玩家在优化什么 |
| --- | --- |
| **打字技术** | 打得准、打得快 → 完美判定 → 作物品质星级 → 售价最高 1.9× |
| **资源规划** | 一天 100 体力，先浇水还是先砍树 → 当天产出 |
| **经营决策** | 种什么、什么时候升级工具、背包要不要扩容 |

几个刻意的设计选择：

- **打错不中断**，只断连击、掉品质；只有超时才失败，且只扣一半体力 —— 惩罚是「变差」而不是「重来」
- **词长即难度**，`hoe` 三个键，`strawberry` 十个键，难度自然分层
- **长周期作物锁地更久**，收益更高，是真正的取舍
- **连击 5/10/20/40 回体力**，越顺越能多做

## 技术栈

- **TypeScript + Vite**，无游戏引擎
- **Canvas 2D** 手写渲染：地形预渲染到离屏 canvas，动态层逐帧画角色/作物/节点/粒子
- **美术零素材**：所有像素图形都是代码画的
- **音效零素材**：WebAudio 实时合成，含五声音阶循环 BGM
- 产物 ~124 KB JS（gzip 48 KB）

### 美术：代码画的，但有统一的视觉规则

全部图形由代码绘制，零外部素材文件。为了保证「不是一堆色块拼贴」，定了一套硬规则（`src/palette.ts`）：

| 规则 | 做法 |
| --- | --- |
| **每个材质固定 5 阶** | `hi` 高光 / `base` 基础 / `mid` 阴影 / `dark` 深阴影 / `line` 描边 |
| **描边不用纯黑** | 用该材质最深一阶（偏暖），避免脏边 |
| **阴影色相偏移** | 不在原色上硬降亮度，而是往偏蓝紫方向偏，避免发灰 |
| **统一光照方向** | 左上打光：高光落在左上，阴影落右下 |
| **柔和落地影** | 三层递减的椭圆，不是单层纯黑 |
| **细节密度** | 草地 9 簇草叶 + 起伏点、路面碎石颗粒、屋顶瓦缝错位、窗户反光斜条、土壤垄沟 |

**四季换色靠色板整体替换**（`src/seasons.ts` 的 `Palette`），所有草/树/花自动跟着季节变，不需要为每个季节准备素材。

**动画**：角色有呼吸浮动与周期性眨眼，行走时手臂/腿反向摆动；作物随风轻摆，成熟时带闪烁微光；动物有走动摇摆与羊毛蓬松度变化。

> 这条路的上限是「精致的程序化像素画」，不是手绘美术。如果之后要上 Steam 且追求更高质感，可以把角色/动物/建筑单独换成像素矩阵或 PNG 精灵图，地形继续程序化——两者可以混用。

## 桌面化 / Steam 路线

目标：**Windows + Electron**，核心栈（TS + Vite + Canvas）不变，只换运行壳。

**为什么不重写引擎**：渲染是 Canvas 2D、零外部素材、零网络、`base:'./'` 已配好，任何 Chromium 壳都能直接跑。重写成 Godot/Unity 等于丢弃全部现有代码，不值。

**为什么选 Electron 而非 Tauri**：单人开发、强项是 TS，Electron 让壳 / Steamworks / 游戏逻辑留在同一门语言；它就是 Chromium，浏览器里测的手感 = 玩家拿到的手感，零渲染输入风险；`steamworks.js` 成熟。Tauri 安装包更小，但 Steamworks 要碰 Rust。

**已就位（本轮）**：`platform.ts` 接缝层 —— 运行时探测 + `StorageAdapter`。浏览器走 localStorage；桌面阶段由 preload 注入 `__FARM_DESKTOP__.storage` 接管为真实文件存档。`capabilities` 开关留给 Steamworks。

**还没做（玩法定型后）**：

1. **存档文件化**：桌面壳里把 `StorageAdapter` 换成文件实现 —— 这是 **Steam 云同步的前提**（云同步靠同步存档文件夹，localStorage 做不到）
2. **Steamworks**：初始化、成就、云存档、统计（`steamworks.js`）
3. **桌面细节**：全屏/窗口、失焦暂停、正常退出、分辨率缩放
4. **打包**：electron-builder 出 Windows 安装包，SteamPipe 上传；代码签名可选
5. **商店素材**：胶囊图、截图、宣传片

> 原则：接缝现在留，壳和 Steamworks 等玩法做完再上，不挡当前开发。
