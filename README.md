# 牧场打字物语 · Typing Farm

> 把《牧场物语》的日常劳作，全部交给指尖。
> 每一种农活都是一次打字 —— `hoe` 开垦、`water` 浇水、`chop` 砍树、`harvest` 收获。

一个跑在浏览器里的像素风农场经营游戏。纯本地运行，存档在 localStorage。

---

### 双语言：中文 / English

顶栏的 **EN / 中文** 按钮切换，选择会记在本地，下次自动生效。

两种模式的**玩法含义不同**：

| 模式 | 打字提示 | 面向 |
| --- | --- | --- |
| 中文 | 显示中文词义（打 `husk` 时提示「谷壳」） | 边玩边认词 |
| English | 提示行变为 `type it out` | 母语者做纯键盘练习 |

实现上没有引 key 资源，而是 `t('中文', 'English')` **成对写在原位置**。字符串在这个项目里是就地生成的，强行抽 key 会让几十处模板字符串变得难读。

名字层用了 Proxy：`TOOLS` / `ANIMAL_DEFS` / `NODE_DEFS` / `TIERS` 在读属性时返回带英文名的副本，`getDef()` 返回本地化后的 `ItemDef`。这样**所有现有的 `.name` 调用点都不用改**。

**当前覆盖范围**（诚实说明）：

| 已英文化 | 还没 |
| --- | --- |
| 顶栏、底栏、HUD（季节/天气/日期/体力/难度） | 背包/图鉴/商店/委托等弹窗的界面文案 |
| 标题画面、难度选择 | 玩法说明长文 |
| 全部物品名（种子/作物/花卉/材料/矿石/产物/加工品/料理/鱼） | NPC 打招呼、送礼反应（对白） |
| 工具名+动作名、工具等级、资源节点名、动物名及畜产品 | 爷爷的遗物、恋爱线、委托文案 |

对白本身的英文（要打的那句）一直是英文，所以英文玩家能玩，但叙事文本仍是中文。
### 存档：可以导出，也可以导入

顶栏 **💾 存档** 按钮。

网页版的存档存在**你自己浏览器的 localStorage 里**，按域名隔离。这带来几个坑：

| 场景 | 后果 |
| --- | --- |
| 换浏览器 / 换电脑 / 无痕模式 | 读不到原来的档 |
| 清浏览器数据 | 档没了 |
| Safari / iOS 七天没访问 | 系统可能清掉 localStorage |
| 站点换域名 | origin 变了，老档读不到 |

所以提供了导出：点「导出文件」会下载一个 `.json`，里面含**主进度 + 学习进度**。

**导入**就是选这个文件恢复。导入前会先校验，并显示文件里的进度（第几天、多少钱），确认后才覆盖，覆盖完自动重载。

格式长这样——每个 key 的值原样存成字符串，导入时不需要理解内容结构，游戏自己的 `normalizeState()` 会处理版本迁移：

```json
{
  "format": "typing-farm-save",
  "formatVersion": 1,
  "gameVersion": "0.1.0",
  "exportedAt": "2025-11-25T...",
  "keys": {
    "typing-farm-save-v1": "<原始 JSON 字符串>",
    "typing-farm-learning-v1": "<原始 JSON 字符串>"
  }
}
```

**白名单导入**：只认这两个 key，存档文件里多出来的 key 一律忽略并提示——防止被塞进奇怪的东西。

> 这也是试玩期最有用的功能：朋友遇到 bug，让他导一份存档发给你，你能原样复现。
### AI 对话（可选，仅桌面版）

村民会**用你正在复习的单词，说自己角色的话**。不开也能玩。

**这不是自由聊天**——给模型是一道有约束的造句任务：

```
角色：阿茂（老农）
说话风格：短句，几乎不用形容词，爱说天气、土、时辰、收成
口头禅：地不会骗人
此刻正在：锄自己的小菜地
和玩家的熟悉程度：3/5 心

必须用上下面这些词中的至少 2 个（原样出现，不要变形）：
loam, reap, husk
```

生成结果要过三关：能解析成 JSON、4~12 个词、**真的用上了至少 2 个约束词**。任何一关不过就静默退回预置台词。

**预生成而非现场等**：进镇/换天时后台为每个村民各生成一句（串行，避免限流），玩家聊天时同步取缓存。跨天自动作废。

**架构**：API key 只在 Electron 主进程，渲染进程通过 preload 白名单调用，`getConfig` 返回值里**刻意不含 apiKey**（只有 `hasKey` 布尔值）。

| 情况 | 行为 |
| --- | --- |
| 浏览器版 | 全部预置台词 |
| 桌面版未配 key | 同上，面板提示去配置 |
| 请求失败 / 超时 / 校验不过 | 这一句退回预置台词 |
| 关掉开关 | 立刻回预置台词 |

桌面版启动：

```bash
pnpm build          # 先构建 dist
pnpm electron       # 启动桌面版
```

存档会落到真实文件：`%APPDATA%/typing-farm/saves/*.json`（原子写入，为 Steam 云同步留好基础）。
配置（含 key）在 `%APPDATA%/typing-farm/llm.json`，**不进游戏存档**。

端到端自检：`electron scripts/electron-smoke.cjs` → 输出 `SMOKE_PASS` 表示 preload 注入、IPC、文件落盘、key 不外泄全部正常。

## 打包发给别人（Windows 便携版）

```bash
pnpm build          # 构建游戏
pnpm package        # 生成 release/TypingFarm-win32-x64.zip
```

产物：

| 路径 | 说明 |
| --- | --- |
| `release/TypingFarm-win32-x64/` | 解压即玩的文件夹 |
| `release/TypingFarm-win32-x64.zip` | **发给别人用这个**（约 100 MB） |

对方解压后双击 `TypingFarm.exe`，不用安装。

> 这不是安装器，是把 Electron 运行时和打包好的游戏拼在一起：
> `resources/app/` 里放 `package.json` + `electron/*.cjs` + `dist/`，
> Electron 会自动从这里加载应用。语言包只保留中文和英文，省十几 MB。

**先确认一件事**：游戏是 ES module，而浏览器不允许 `file://` 打开 module 脚本。
Electron 里可以（实测 `window.__farm` 有值、标题页难度卡渲染出 3 个），
所以不需要自定义 `app://` 协议。

## 操作

| 按键 | 作用 |
| --- | --- |
| **点击地面** | **自动走过去（推荐，这样左手能一直放在打字键上）** |
| `WASD` / 方向键 | 移动（会打断自动移动） |
| `Shift` | 奔跑 |
| `空格` / `E` | 使用手持物（面前那一格） |
| `1` ~ `8` | 选择快捷栏 |
| `Q` | 循环快捷栏 |
| `Tab` / `B` | 打开背包 |
| `Esc` | 关闭弹窗 |

**为什么推荐点击移动**：这是个打字游戏。左手常驻 WASD 意味着每次要打字时都得把手移回键盘区，**切换成本很高**。用鼠标点地面移动，左手就可以一直待在打字位。点水面、墙、树这类不能站的地方，会自动走到它旁边。

**打字前请把输入法切到英文。**

## 难度

第一次玩觉得打字跟不上？**开局可以选难度**，游戏中途也能随时改（点顶栏的难度徽章）。

| 难度 | 时限 | 容错 | 词长 | 超时惩罚 | 打错 |
| --- | --- | --- | --- | --- | --- |
| 🌱 轻松 | **+70%** | **+2 次** | **短一档** | 只扣 1/4 体力 | **不清连击** |
| 🌤️ 标准 | 正常 | 按工具等级 | 正常 | 扣一半体力 | 清连击 |
| 🔥 挑战 | -15% | -1 次 | 长一档 | **扣满** | 清连击 |

三档的实际差别（同一个词 `harvest`）：

- 轻松 6511 ms / 标准 3830 ms / 挑战 3256 ms
- 轻松取到 4 字母词（`husk` `grow` `sown`），标准 5 字母（`plant` `soil` `reap`），挑战 6 字母（`bundle` `sprout` `water`）

**轻松档的四个改动合在一起**，是给新手的完整缓冲：时间更宽、允许打错、词更短、失误代价小，而且**打错不会清连击**（连击关系到体力回复）。

**难度只影响打字手感，不影响收益**——避免「想赚钱就必须玩难」的压迫感。

**中文提示始终显示**，而且显示的是**词义**不是动作名：打 `husk` 时提示「谷壳」、`bait` 是「鱼饵」、`sown` 是「已播种」。动作名在上一行（「开垦 · 铜锄头」）。这样一边玩一边认词，不会把 `sown` 误记成「开垦」。

## 核心系统

### 五把工具，五种打字节奏

工具不是数值乘数，每把都有自己的手感：

| 工具 | 目标 | 打字模式 | 体力 | 一句话 |
| --- | --- | --- | --- | --- |
| 🔨 锄头 | 未开垦的地 | 一个词 | 4 | `hoe` / `dig` / `plow` |
| 🚿 水壶 | 已播种的作物 | 一个词 | 2 | `water` / `soak` / `drench` |
| 🪓 斧头 | 树 | **同一词连打 3 遍** | 6 | 连砍三下，树就倒了 |
| ⛏️ 镐 | 岩石 | **长词重击**（时限 -20%） | 7 | 两下敲碎一块 |
| 🌾 镰刀 | 杂草 | **3 个短词快打**（每个 2.5 秒） | 2 | `cut` `mow` `trim` |
| 🎣 钓竿 | 池塘水面 | **等待 + 瞬间反应** | 5 | 抛竿打 `cast`，咬钩后 1.2 秒内按空格 |

拿错工具时，只要快捷栏里有对的那把，会**自动换上**并提示。

### 背包与快捷栏

- 背包初始 **16 格**，可扩容到 24 / 32（2000G / 5000G）
- 快捷栏 **8 格**，放工具和种子，`1~8` 直接选
- 作物按「种类 + 品质」分堆，5 星萝卜和 1 星萝卜不混
- 背包满了会**拒绝操作**并提示，绝不静默吞物品

### 材料与升级

砍树得木材、挖石得石材、割草得纤维。工具升级需要材料，于是**想去升级锄头，就得先拿起斧头和镐**：

| 升级 | 金币 | 材料 |
| --- | --- | --- |
| 银 | 600 | 木材 ×8（斧/镐要石材 ×10） |
| 金 | 1800 | 石材 ×20 |
| 秘银 | 4200 | 木材 ×30 + 石材 ×30 |

等级效果：银 = 容错 1 次；金 = 时限 +25%；秘银 = 容错 2 次 + 掉落翻倍 / 范围操作。

### 工具耐久

每把工具有耐久，**每干一次活就磨损**（徒手的播种、收获不算）。耐久见底就坏了，必须修好才能继续用。

| 等级 | 耐久上限 | 每次磨损 | 修满费用 |
| --- | --- | --- | --- |
| 铜 | 100 | 1 | 60G |
| 银 | 140 | 1 | 120G |
| 金 | 180 | 1 | 180G |
| 秘银 | 240 | 0.5 | 240G |

- 耐久低于 **20%** 会提示「快磨坏了」，坏了会提示「得修一修」
- 快捷栏每把工具下方有一条**耐久条**，绿→橙→红
- 订购箱「工具」区每行显示 `耐久 85/100`，有磨损时出现「修 60G」按钮
- **升级会顺带修满**——换了把新工具，耐久按新等级的上限重置
- **修理只收金币，不收材料**：否则「修工具要石材 → 石材要镐挖 → 镐也坏了」会死锁

按铜级算，100 耐久大约能干 3~4 天的活，撑一周就得修一次——修理变成了像浇水一样的例行小事，但不至于逼玩家天天跑。

### 资源节点

木材有**四档来源**，越大的树越费体力、但每点体力换到的木材越多：

| 节点 | 数量 | 斧头动作 | 产出 | 刷新 | 特点 |
| --- | --- | --- | --- | --- | --- |
| 灌木 | 6 丛 | 1 次 | 木材 1 | 2 天 | 矮，**可以从上面走过去** |
| 小树 | 5 棵 | 1 次 | 木材 2~3 | 4 天 | 细干窄冠 |
| 大树 | 5 棵 | 2 次 | 木材 5~8 | 7 天 | 粗干带根扩，**效率最高** |
| 老树桩 | 3 个 | 1 次 | 木材 2~3 | **不重生** | 一次性，挖掉永久消失 |

> 一次斧头动作 = 同一串词连打 3 遍，固定 6 体力。所以「木材 ÷ 体力」：
> 灌木 1、小树 2.5、大树 2.5+、树桩 3。大树和树桩更划算，灌木胜在两天就长回来。

| 节点 | 数量 | 击打 | 产出 | 刷新 |
| --- | --- | --- | --- | --- |
| 岩石 | 8 块 | 2 次 | 石材 2~3 | 5 天后恢复 |
| 杂草 | 每天 5~8 丛 | 1 次 | 纤维 1~2 | 每天重新长出（上限 20） |

**地图边界与树篱不是"一棵棵树"，是茂密的灌木墙**：每格叠六团叶簇（贴地左/中/右 + 中层两团 + 顶层一团），贴地三团的半径都超过半格，所以**相邻格子必然重叠**——横向覆盖接近 100%，没有可以钻过去的缝；顶部高度按格子哈希起伏，底部压一条暗带封住地面。

### 钓鱼

池塘边面朝水面按空格，拿起钓竿。流程和农活完全不同：

```
打一个词抛竿  →  盯着浮标（等 0.9~3.6 秒）  →  咬钩！1.2 秒内按空格
              →  打一个词收线  →  上钩
```

- **反应越快星级越高**：窗口前 15% 内提竿是 5 星，越慢越低，最低 1 星
- 等太久会「鱼吐钩跑了」，抛竿太早只会提示「还早呢」
- 收线要打的词**跟着鱼的价值走**：30G 的鲤鱼只要打入门档短词，520G 的锦鲤要打高手档长词
- 钓竿等级提升咬钩窗口：铜 1.2s → 银 1.45s → 金 1.7s → 秘银 1.95s，秘银还会让稀有鱼更容易上钩

| 鱼 | 售价 | 收线难度档 | 稀有度 |
| --- | --- | --- | --- |
| 鲤鱼 | 30 | 入门 | 常见 |
| 鳊鱼 | 45 | 入门 | 常见 |
| 鳟鱼 | 70 | 轻松 | 普通 |
| 鲈鱼 | 95 | 轻松 | 普通 |
| 鲶鱼 | 130 | 中等 | 少见 |
| 鲑鱼 | 180 | 进阶 | 少见 |
| 鳗鱼 | 230 | 进阶 | 稀有 |
| 鲟鱼 | 330 | 困难 | 稀有 |
| 锦鲤 | 520 | 高手 | 传说 |

一条平均约 77G，是**可再生的现金流**——不像树和岩石有恢复周期，池塘随时能钓。

### 动物：每天必做的小事

动物补上一段固定照料循环，和钓鱼互补（钓鱼考反应、随时能做；动物考照料、每天必做）。

**鸡 🐔 / 牛 🐄 / 羊 🐑**：订购箱购买（鸡 600G / 牛 2200G / 羊 1200G），养在地图下方的鸡舍 / 牛棚围栏里（牛羊同住牛棚），每种最多 6 只。动物会在围栏里溜达。走到动物身边面朝它按空格，打开照料面板。

| 动作 | 节奏 | 体力 / 时间 | 效果 |
| --- | --- | --- | --- |
| 喂食 | 一个词 | 2 / 10min | 当天喂了，**明天才有**蛋 / 奶；心情 +8 |
| 捡蛋 / 挤奶 | 捡蛋一个词；**挤奶三连短词** | 2 / 5min · 4 / 15min | 收产物进背包 |
| 剪毛 | **三连短词** | 4 / 20min | 羊毛满 100% 才能剪，剪完归零 |
| 抚摸 | 一个词 | 1 / 5min | 心情 +6 |

**心情 → 品质**：心情 0~100 决定蛋 / 奶的基础星级（每 25 点一星），打得完美再 +1。喂食 + 抚摸涨心情，**饿着过夜掉 15**。于是「把动物照顾好」和「打字打得准」一样能变现。

**产物**：鸡蛋 70G / 牛奶 160G / 羊毛 280G（基准价，随品质最高 1.9×），和作物、鱼一样在出货箱卖。定位是**中期投资**——比种菜稳、比钓鱼省心，但要天天照料。

**羊的节奏不一样**：它不产「每日产物」，而是**攒羊毛**。每晚喂食 +34%，约 3 天攒满 100% 才能剪一次。剪一次 280G，比蛋奶值钱，但周期长——是「耐心换高单价」的选择。羊的毛长满时身体会明显变蓬松，一眼能看出该剪了。

**动物命名**：每只动物有默认名（鸡1、羊2…），面板里点「改名」可以起个自己的。

新买的动物带一份「见面礼」产物，让你立刻见到收获动作，随后学会「喂了明天才有」的节奏。

### 繁殖：让动物会「长大」

不只是「过夜随机多一只」，而是完整的成长链：

```
两只同类成年动物（心情 ≥70、当天都喂过）
   → 配种（打一个词）
   → 母方怀孕 2~3 天
   → 生下一只幼崽
   → 幼崽养 4 天长大
   → 成年后才开始产出
```

| 动物 | 怀孕天数 |
| --- | --- |
| 鸡 | 2 天 |
| 牛 / 羊 | 3 天 |

**几个刻意的设计**：

- **幼崽不产出**：`isProductReady` 直接返回 false，羊毛也不涨。养大前只有投入没有回报，成长才有分量
- **幼崽画小一号**（0.62 倍）并标「幼」，怀孕的标「♥」——围栏里一眼看出状态
- **配种消耗双方的当日喂食**：防止同一天反复配种刷数量
- **只让玩家点的那只怀孕**，配偶不怀孕，避免一次配种双倍产出
- **围栏上限 6 只**（含幼崽），满了就不生
- **幼崽长大后给一份产出**，让玩家立刻看到「养大了」的回报

**配种条件**：两只都成年、心情 ≥70、当天都喂过、都没怀孕。面板会直接告诉你缺什么。

### 花卉：社交筹码，不是经济作物

每季还有**一种花**，四季各一：

| 季 | 花 |
| --- | --- |
| 春 | 🌷 郁金香 `tulip` |
| 夏 | 🌸 百合 `lily` |
| 秋 | 🌼 雏菊 `daisy` |
| 冬 | 🌺 山茶 `camellia` |

**花是亏钱的**：种子 70G，卖只值 45G。种它是为了送人。

| 礼物 | 好感 |
| --- | --- |
| 普通礼物（中性） | 5 |
| 普通礼物（对方喜欢） | 15 |
| **花（对方不喜欢也不算）** | **10** |
| **花（对方喜欢花）** | **20** |

所以花的价值在于**普适性**：不管送给谁都不亏，送给爱花的人（阿晴）比送她最爱的草莓还好（20 vs 15）。

> 这是给社交系统补上「通用筹码」。原来只有「投其所好」一条路，得先猜每个村民喜欢什么；花是不用猜的那条路，代价是亏钱和 4 天时间。

### 加工台：给产物第二条出路

住宅里多了一台**加工台**（桌子右边）。把原料放进去，等它做好。

| 加工品 | 原料 | 时间 | 售价 | 增值 |
| --- | --- | --- | --- | --- |
| 🧀 奶酪 | 牛奶 ×1 | 4h | 420G | **+260G** |
| 🧈 黄油 | 牛奶 ×2 | 5h | 780G | **+460G** |
| 🪡 毛线 | 羊毛 ×1 | 6h | 520G | **+240G** |
| 🍓 草莓酱 | 草莓 ×2 | 5h | 1900G | **+620G** |
| 🥫 番茄酱 | 番茄 ×2 | 3h | 880G | **+340G** |

**三条设计原则**：

1. **必须花时间**——不是免费的点击增值，你得等几小时（会跨天）
2. **一次只能做一样**——单槽位，避免挂机批量刷
3. **品质继承原料**——用 5 星牛奶做出来的就是 5 星奶酪

加工品现在只是「更值钱的卖出品」，但它真正的用途在后面：**它们是烹饪的食材**。所以这一步是给料理系统铺的地基。

> 为什么加工要在烹饪之前做？因为如果直接从「牛奶」跳到「蛋糕」，配方只能堆原始食材，链条太短、没有可玩环节。中间加一层，玩家才有「原料 → 半成品 → 成品」的逐步升级感。

### 灶台：料理能吃，也能卖

住宅右下角是**灶台**。做菜即时完成（花 3 体力 + 20 分钟），但料理有**两种用途**：

| 料理 | 原料 | 售价 | 回体力 |
| --- | --- | --- | --- |
| 🍲 蔬菜汤 | 萝卜 + 洋葱 | 380G | 25 |
| 🍳 煎蛋 | 鸡蛋 ×2 | 210G | 20 |
| 🥣 土豆泥 | 土豆 ×2 | 440G | 25 |
| 🧀 奶酪焗土豆 | 奶酪 + 土豆 ×2 | 1070G | 40 |
| 🍝 番茄意面 | 番茄酱 + 玉米 | 1850G | 45 |
| 🍞 草莓酱吐司 | 草莓酱 + 鸡蛋 | 2950G | 35 |
| 🍱 丰收大餐 | 奶酪 + 南瓜 + 玉米 | 2300G | **60** |
| 🍜 奶油浓汤 | 黄油 + 牛奶 + 土豆 | 1630G | 50 |

**分三档**：家常（原料在手边）→ 像样的一餐（用上加工品）→ 大餐（多种高级食材）。

**「能吃」是料理和加工品的本质区别**。加工品只是更值钱的卖出品；料理能回体力——白天干活累了，回家吃一顿继续干。这让「吃饭」成了游戏循环的一部分，而不只是一条赚钱路径。

> 这也补上了原本缺失的一环：以前体力只能靠睡觉和连击回复，现在有了主动补充的手段。

**季节视觉**：地图随季节换色板——春嫩绿、夏深绿、秋橙黄、冬雪白，树冠同步变色。换季时重绘底图，冬天不开花。

**季节天气**：春雨多（35%）、夏晴（15% 降水）、秋爽（20%）、冬飘雪（40%）。**雨自动浇灌，雪不会**——冬天得手动浇水，多一件例行小事。

**提示**：HUD 显示「季节 · 第几天」；订购箱给每种种子标「当季 / 反季慢一倍」；换季那晚弹提示；反季播种会提醒。

### 节日：每季最后一天的期待

每季第 8 天（第 8 / 16 / 24 / 32 天）是节日，**只在当天有效**，给四季加上期待感。

| 季节 | 节日 | 效果 |
| --- | --- | --- |
| 春 | 🌱 播种祭 | 种子半价（商店显示划线原价） |
| 夏 | 🎆 夏日祭 | 体力消耗减半 |
| 秋 | 🌾 丰收祭 | 出货价格 +50% |
| 冬 | ✨ 星霜祭 | 所有产出品质 +1 星 |

四个节日对应四种资源**加速器**：更便宜地投入（种子）、更省力地干活（体力）、更高地变现（出货）、更好地提质（品质）—— 都是「今天该干什么」的节奏提示。

- **睡前预告**：第 7 天睡觉时会提示「明天是播种祭！」
- **HUD 徽章**：节日当天顶栏出现带呼吸动画的节日标签
- **出货提示**：丰收祭当天出货面板顶部标明「今天出货价格 +50%」

节日只影响当天，不做累计加成，避免鼓励「攒到节日再玩」的拖延策略。

### 恋爱线：目前开放 2 人

10 个村民里，**阿晴和阿梅可以攻略**（其余 8 人是纯朋友）。

```
好感 2 心 → 事件①  →  3 心 → 事件②  →  4 心 → 事件③  →  5 心 → 告白
```

**三个事件 + 一次告白**，每次都是「听她说一段 → 打一句你的回应」。不另开系统，还是打字。

| 角色 | 三个事件的题眼 | 告白要说的 |
| --- | --- | --- |
| 🌸 阿晴 | 花变少了 / 朋友都走了 / 她买过车票又回来 | `i want to stay with you` |
| 🍺 阿梅 | 一个人撑店六年 / 这条街少了五家店 / 她走到镇口又回头 | `i want to spend my life here` |

**两个角色的写法完全不同**：

- 阿晴是**留白式**的——她说话很轻，用的是省略号（「……嗯。」「那就好。」），情绪藏在动作里（"她往你这边靠了一点，肩膀碰到了。两个人都没动。"）
- 阿梅是**摊开式**的——她会自嘲、会喝酒、会直接说"你可想好了，我这人不好伺候"

同一件事（讲自己的过去），阿晴说"朋友走了，车票买了又回来"，阿梅说"我二十五岁那年行李都收拾好了，走到镇口回头看了一眼招牌"。**一个是怀念，一个是不甘。**

**细节设计**：

- 事件必须**当天没聊过**才能触发（避免一天刷完）
- 看出事件的那次聊天加 10 点好感（心事本身就是更深的交流）
- 告白要求 **5 心 + 三个事件全部完成**，缺一样都不给按
- 成为恋人后，面板显示「💗 你们在一起了」，按钮回归普通——**恋爱不是新菜单，是关系的状态**

### 生日：送礼要挑日子

每个村民一年过一次生日，**当天送礼好感翻倍**。

| 村民 | 生日 | 那天早上会说 |
| --- | --- | --- |
| 🧑‍🌾 阿茂 | 第 5 天（春） | 「生日？……我自个儿都忘了。你有心了。」 |
| 🎣 小渔 | 第 13 天（夏） | 「哈，你还记得！晚上我请你吃鱼。」 |
| 🧺 掌柜 | 第 21 天（秋） | 「记得我生日的人不多。这份心意我收下了。」 |

- 生日当天**聊天内容也换**：阿茂会说 `you remembered my birthday`（你记得我的生日），不再是日常的农事闲聊
- 面板顶部出现「🎂 今天是 阿茂 的生日！送礼好感 ×2」
- 当天进入游戏会给一条提示
- **讨厌的东西送出去仍然掉好感**，生日不救——不喜欢就是不喜欢

### 旧木箱：爷爷留下的四件东西

住宅角落有一个**旧木箱**（床边，x18-19, y14）。里面放着爷爷的遗物，**按天数依次解锁**。

| 天数 | 物件 | 讲了什么 |
| --- | --- | --- |
| 第 1 天 | ✉️ 一封信 | 他为什么把地留给你——「别急着卖。先住满一年。」 |
| 第 9 天 | 📷 一张旧照片 | 他年轻时也和你一样大，第一年收成也不好 |
| 第 17 天 | 🔨 一把旧锄头 | 「手上有茧，心里才踏实。」柄上的凹陷正好合你的掌心 |
| 第 25 天 | 📒 一本记账本 | 四年前停笔。封底写着「地不会骗人。你对它好，它就记着。」 |

**最后一本账本埋了一条线索**：

> ……这句话你在镇上听过。阿茂也这么说。

爷爷的处世之道和阿茂的口头禅一模一样——暗示两人有旧交情。这类联动不做提示、不做任务，只是让玩家自己发现。

**写法上的取舍**：每段只给**一个具体物件 + 一两句原话**，不解释太多。情感留给玩家自己补完——直接写"他很爱你"是无效的，写"落款笔画有点抖"才有效。

未解锁的显示「？？？还要等到第 N 天」，看过的显示「再看一遍」。

### 矿洞：高级材料的唯一来源

农场北边有个石拱门（x13, y3），走进去就能下矿。

**5 层，越深矿越好**：

| 层 | 矿石 | 节点数 |
| --- | --- | --- |
| 1~2 | 铜矿 | 4 |
| 3~4 | 铜矿 ×2 + 铁矿 ×3 | 5 |
| 5 | 铁矿 ×3 + 宝石 ×2 | 5 |

- 每层有**上行梯子**和**下行梯子**，第 1 层的上行梯子直接回农场
- 矿脉**不重生**——出洞再进来会重新生成，所以可以反复刷
- 矿石是**工具升级的硬通货**：银→金 要铜矿，金→秘银 要铜矿 + 铁矿 + 宝石

| 矿石 | 售价 | 用途 |
| --- | --- | --- |
| 🟤 铜矿 | 80G | 金级升级 |
| ⬛ 铁矿 | 200G | 秘银级升级 |
| 💎 宝石 | 600G | 秘银级升级 |

> 这是给「工具升级」补上的资源链条。原来只靠木材+石材，砍树挖石就够了；现在高级工具必须有矿洞产出，矿洞才有存在的意义——否则它只是又一个能挖石头的地方。

### 委托板：把四条生产链串起来

小镇广场上立着一块**委托板**（x37, y10）。镇上的人有事请你帮忙。

**每天刷新 2~3 条**，保留 2 天，过期撤下。

| 阶段 | 天数 | 委托内容 |
| --- | --- | --- |
| 前期 | 1~6 天 | 基础作物、蛋奶、木材石材 |
| 中期 | 7~14 天 | 高价作物、羊毛、**加工品**（奶酪/毛线/番茄酱）、花卉 |
| 后期 | 15 天+ | 稀有作物、**料理**（丰收大餐/番茄意面）、矿石 |

**这是委托板最重要的作用**——到了后期会出现「交 1 份丰收大餐」这类委托，玩家必须**走完种地 → 加工 → 烹饪整条链**才能完成。它把原本平行的四条产线变成有目标的任务。

**报酬**：原料售价 × 1.6~2.1，外加固定跑腿费。比直接卖划算，但物品是随机指定的，你没法专门为委托生产——所以它的真实价值是「顺便清理库存」。

**还加好感**：每条委托加 8~16 点好感，是唯一能「边赚钱边刷好感」的途径。

**操作**：有货就能直接交付，不需要先「接任务」——少一步操作。

### 词库：打什么词，和做什么事是分开的

动作只声明「我需要一个多难的词」，词本身来自词库。**难度 = 价值**：值钱的东西要求更难的词。

难度不只看长度。每个词有一个**难度分**，以字母数为基础，再按真实手感修正：

- 连续重复字符（`zzzz`）→ 减分，按住一个键连打太容易
- 字符多样性低 → 减分
- 同手连击（左手或右手连续敲）→ 加分，比左右交替慢
- 罕见字母 q/z/x/j → 少量加分

所以 `zzzz` 和 `plow` 一样是 4 个字母，但难度分 1.15 vs 4.5，**时限也差 34%**。

价值映射到 7 个难度档：

| 价值 | 难度档 | 大致词长 |
| --- | --- | --- |
| < 50G | 入门 | 3~4 |
| 50~100G | 轻松 | 4 |
| 100~180G | 中等 | 4~5 |
| 180~300G | 进阶 | 5~6 |
| 300~450G | 困难 | 6~7 |
| 450~650G | 高手 | 7~8 |
| > 650G | 极限 | 9+ |

实测：草莓（640G）收获打 `harvest` `seedling`，萝卜（90G）打 `husk` `loam`。

农场主题词分六个分类：**耕作 / 砍树 / 挖矿 / 割草 / 钓鱼 / 照料**，共 203 个词，**每个词都配了中文释义**，每档都有覆盖。

**取词用洗牌袋**：把该档的词洗牌后依次发完再重洗，保证一轮内不重复，再叠加「最近 8 词避让」，不会来回就那几个。

### 学习机制：靠「跨天重复」而不是挖空

游戏里**始终完整显示单词**——你的任务一直是「把看到的词打出来」。这一点很关键：本作是打字游戏，不是拼写测试。

> 曾试过「挖空（只留首字母）逼玩家回忆」，但被否掉了：那是 Anki 那类拼写练习，塞进打字游戏会**脱离设定**，而且难度是跳变式的（前两个词正常打，第三个突然变填空题）。

所以记忆机制只靠一件事：**跨天重复**。

**掌握 = 在 3 个不同天各打对这个词**

- 每个词记录「在几个不同天打对过一次」
- **同一天重复打对只算 1 次**
- 累计 **3 个不同天** = 掌握

这条能堵死「一天连打 20 遍刷满」——同一天的重复不计数，必须隔天再见到才累计。间隔重复的效果依然在，只是效率比主动回忆低一些——但那正是「游戏」该付出的代价。

**每日新词配额：12 个**

- 每天最多引入 12 个新词，配额用完后只从**已学过**的词里出
- 避免第一天就被 2945 个陌生词淹没
- 睡一觉重置配额

**取词优先级**（替代原来的洗牌袋）

| 优先级 | 词的状态 | 出现概率 |
|---|---|---|
| 1 | 学过但还没掌握 | 高（该复习了） |
| 2 | 没见过的 | 中（受每日配额限制） |
| 3 | 已掌握 | 低（偶尔回顾） |

刚出现过的 12 个词会被排除，保证有间隔但不至于「一轮内绝不重复」——**原来那个"保证不重复"的设计恰恰是反学习的**：你今天打了 `abandon`，一周后才再遇到，那时早忘光了。

**进度在词库界面可见**：已学 / 已掌握 / 今日新词（如 `8/12`）。

### 自定义词库：支持 `词 释义`

新建词库时可以一行一个地写 **英文词 + 中文释义**：

```
abandon 放弃
absorb 吸收
resilient 有韧性的
```

支持的写法：
- `abandon 放弃`（空格分隔）
- `abandon,放弃`（逗号）
- `apple 苹果; banana 香蕉`（分号分隔多个条目）
- `abandon absorb abstract`（纯单词列表，无释义——这时会用内置词义表补）

带释义的词会**优先显示你自己的释义**，所以可以导入你自己整理的四六级、考研、专业词汇表，边玩边背。

**自定义词库**（顶栏 📖 词库）：

- 粘贴一串单词（空格、逗号、换行都行），只保留英文字母，长度 2~14，按难度分自动归档
- 保存前有**难度分布预览**，输入时实时显示「识别 N 词 · 入门×2 中等×1 …」
- 界面有一张**档位覆盖表**：每类 × 每档的词数，空档标红并提示「会向邻近档借词」
- 可绑定到某个分类，或「全部动作」
- **一旦启用某分类的自定义词库，该分类就只用你的词**，内置词不再掺进来
- 支持启用/停用/编辑/删除，以及 JSON 或纯文本导入导出
- 存在 `localStorage` 的 `typing-farm-wordsets-v1`，与游戏存档独立

## 一天是怎么过的

```
06:00 起床
  ↓  走到目标旁 → 空格 → 打字 → 完成一次劳作（时间 +n 分钟，消耗体力）
  ↓  22:00 之后劳作，体力消耗翻倍
  ↓  凌晨 2:00 还没睡 → 直接累倒
回屋睡觉
  ↓  浇过水的作物生长一阶段，没浇水的原地不动
  ↓  树/岩石按天数恢复，杂草重新长出
  ↓  天气重掷（25% 下雨，雨天自动浇水）
次日 06:00，体力回满
```

体力耗尽会晕倒，扣 20% 金币当医药费。

## 设计思路

游戏乐趣来自三条互相牵制的轴：

| 轴 | 玩家在优化什么 |
| --- | --- |
| **打字技术** | 打得准、打得快 → 完美判定 → 作物品质星级 → 售价最高 1.9× |
| **资源规划** | 一天 100 体力，先浇水还是先砍树 → 当天产出 |
| **经营决策** | 种什么、什么时候升级工具、背包要不要扩容 |

几个刻意的设计选择：

- **打错不中断**，只断连击、掉品质；只有超时才失败，且只扣一半体力 —— 惩罚是「变差」而不是「重来」
- **词长即难度**，`hoe` 三个键，`strawberry` 十个键，难度自然分层
- **长周期作物锁地更久**，收益更高，是真正的取舍
- **连击 5/10/20/40 回体力**，越顺越能多做

## 技术栈

- **TypeScript + Vite**，无游戏引擎
- **Canvas 2D** 手写渲染：地形预渲染到离屏 canvas，动态层逐帧画角色/作物/节点/粒子
- **美术零素材**：所有像素图形都是代码画的
- **音效零素材**：WebAudio 实时合成，含五声音阶循环 BGM
- 产物 ~284 KB JS（gzip 113 KB，其中词表约 41 KB）

### 美术：代码画的，但有统一的视觉规则

全部图形由代码绘制，零外部素材文件。为了保证「不是一堆色块拼贴」，定了一套硬规则（`src/palette.ts`）：

| 规则 | 做法 |
| --- | --- |
| **每个材质固定 5 阶** | `hi` 高光 / `base` 基础 / `mid` 阴影 / `dark` 深阴影 / `line` 描边 |
| **描边不用纯黑** | 用该材质最深一阶（偏暖），避免脏边 |
| **阴影色相偏移** | 不在原色上硬降亮度，而是往偏蓝紫方向偏，避免发灰 |
| **统一光照方向** | 左上打光：高光落在左上，阴影落右下 |
| **柔和落地影** | 三层递减的椭圆，不是单层纯黑 |
| **细节密度** | 草地 9 簇草叶 + 起伏点、路面碎石颗粒、屋顶瓦缝错位、窗户反光斜条、土壤垄沟 |

**四季换色靠色板整体替换**（`src/seasons.ts` 的 `Palette`），所有草/树/花自动跟着季节变，不需要为每个季节准备素材。

**动画**：角色有呼吸浮动与周期性眨眼，行走时手臂/腿反向摆动；作物随风轻摆，成熟时带闪烁微光；动物有走动摇摆与羊毛蓬松度变化。

> 这条路的上限是「精致的程序化像素画」，不是手绘美术。如果之后要上 Steam 且追求更高质感，可以把角色/动物/建筑单独换成像素矩阵或 PNG 精灵图，地形继续程序化——两者可以混用。

## 桌面化 / Steam 路线

目标：**Windows + Electron**，核心栈（TS + Vite + Canvas）不变，只换运行壳。

**为什么不重写引擎**：渲染是 Canvas 2D、零外部素材、零网络、`base:'./'` 已配好，任何 Chromium 壳都能直接跑。重写成 Godot/Unity 等于丢弃全部现有代码，不值。

**为什么选 Electron 而非 Tauri**：单人开发、强项是 TS，Electron 让壳 / Steamworks / 游戏逻辑留在同一门语言；它就是 Chromium，浏览器里测的手感 = 玩家拿到的手感，零渲染输入风险；`steamworks.js` 成熟。Tauri 安装包更小，但 Steamworks 要碰 Rust。

**已就位（本轮）**：`platform.ts` 接缝层 —— 运行时探测 + `StorageAdapter`。浏览器走 localStorage；桌面阶段由 preload 注入 `__FARM_DESKTOP__.storage` 接管为真实文件存档。`capabilities` 开关留给 Steamworks。

**还没做（玩法定型后）**：

1. **存档文件化**：桌面壳里把 `StorageAdapter` 换成文件实现 —— 这是 **Steam 云同步的前提**（云同步靠同步存档文件夹，localStorage 做不到）
2. **Steamworks**：初始化、成就、云存档、统计（`steamworks.js`）
3. **桌面细节**：全屏/窗口、失焦暂停、正常退出、分辨率缩放
4. **打包**：electron-builder 出 Windows 安装包，SteamPipe 上传；代码签名可选
5. **商店素材**：胶囊图、截图、宣传片

> 原则：接缝现在留，壳和 Steamworks 等玩法做完再上，不挡当前开发。
